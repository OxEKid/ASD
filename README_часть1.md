# Антиплагиат — часть 1: загрузка сдачи, config и CLI

Автор части: Савельев Я. В., гр. 4516.

## Что делает
- принимает ZIP-архив со сдачей группы;
- раскладывает файлы по студентам (папка студента, вложенный архив студента или файл в корне вида `Фамилия_lab.py`);
- делит файлы на код (`.py`, `.cpp`, `.h`, `.hpp`, `.java`) и отчёты (`.docx`, `.pdf`), определяет язык;
- пропускает повреждённые, пустые, слишком большие и неподдерживаемые файлы с сообщением об ошибке;
- исправляет русские имена файлов из архивов Windows, защищает от путей `../`;
- читает настройки из `config.json` (пороги сходства, размер шингла, расширения);
- строит список всех пар «кто с кем» и сохраняет `result/manifest.json` для частей 2–5.

## Запуск
Нужен только Python 3.10+ (сторонние библиотеки не нужны).

```
python make_test_archive.py          # создать тестовый архив test_data/сдача.zip
python main.py test_data/сдача.zip   # проверить сдачу
python main.py test_data/сдача.zip --extract --threshold-code 50
python main.py -h                    # справка по параметрам
python -m unittest discover -s tests -t .   # тесты
```

## Что получают остальные части
`load_zip(путь, config)` возвращает `LoadResult`:
- `files` — список `SubmissionFile(student, path, kind, language, size, content)`;
- `errors` — список сообщений о пропущенных файлах;
- `students()`, `files_of(student, kind)`.

`make_pairs(students)` — все пары студентов. Части 2 и 3 берут файлы с `kind == "code"`, часть 4 — с `kind == "report"`, часть 5 — `manifest.json` и пары.
